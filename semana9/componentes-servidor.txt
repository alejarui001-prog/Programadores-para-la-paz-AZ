Sistema operativo:
Es el software principal del equipo. Administra los recursos del hardware y permite ejecutar aplicaciones y servicios.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador y crear servidores.

Aplicación server.js:
Es el archivo que contiene la lógica del servidor y define las rutas que responderán a las solicitudes.

Puerto:
Es un punto de comunicación que permite que el servidor reciba solicitudes. En esta actividad se utiliza el puerto 3000.

Logs:
Son registros que almacenan eventos y actividades del sistema. Ayudan a monitorear el funcionamiento y detectar errores.
