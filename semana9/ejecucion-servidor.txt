Al ejecutar el comando node server.js se inicia el servidor Node.js.

En la terminal aparece el mensaje:
"Servidor ejecutándose en puerto 3000".

Cuando se visita la ruta /estado, el servidor responde con un objeto JSON indicando que el servidor está funcionando y que pertenece a una API comunitaria.

Respuesta de ejemplo:

{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
